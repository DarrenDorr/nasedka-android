# Безопасность

Основные функции приложения работают автономно. Разрешение `INTERNET` используется исключительно для чтения новостей и информации о версиях из публичного GitHub. Записи хранятся в локальной SQLite базе; Android backup отключён, экспорт CSV выполняется только по инициативе пользователя. Не добавляйте секреты и персональные данные в публичные Issues.

Проект не управляет сетевым напряжением 220 В, нагревательными элементами или устройством переворота. Любые модификации управления оборудованием в будущих версиях требуют проверок отказоустойчивости и электробезопасности. Не полагайтесь исключительно на телефон для обеспечения жизни животных.

О проблемах безопасности сообщайте через **GitHub Security → Advisories → Report a vulnerability** (если у проекта активирована приватная подача сообщений). Не публикуйте секреты и подробные инструкции эксплуатации уязвимостей в открытых Issues. До включения канала не размещайте чувствительную информацию публично.


## Обновления

Обновления через GitHub допускаются только для GitHub-канала. Проверяется SHA-256 APK из GitHub Releases API, затем системный установщик Android проверяет пакет и подпись. Проверка контрольной суммы не заменяет подпись. При выпуске используйте один постоянный релизный ключ и увеличивайте `versionCode`. Закрытый ключ никогда не храните в открытом GitHub-репозитории. Для Google Play и RuStore применяйте их собственные механизмы обновления.


**Статус проверки на 17.11.2026:** исходный код подготовлен, но полноценная сборка и испытания на физических устройствах не проведены. Матрица `security/NOTIFICATION_TEST_MATRIX.md` не должна отмечаться `PASS` до получения доказательств.
