# Участие в разработке

Проект открыт для всех. Создавайте Issue с воспроизводимыми шагами, моделью телефона, версией Android и ожидаемым результатом. Не публикуйте личные записи, серийные номера оборудования или приватные данные в Issues.

Для изменений создайте отдельную ветку и Pull Request в `main`. Проверьте локальную сборку, `gradle testGithubDebugUnitTest assembleGithubDebug` и соответствие новой логики календаря инструкции либо укажите независимый источник рекомендаций. Не добавляйте в репозиторий закрытые ключи, APK, личные журналы или чужие инструкции целиком без разрешения правообладателя.

Код проекта лицензирован по Apache 2.0; отправляя вклад, вы соглашаетесь на его распространение на условиях этой лицензии.


## Новости, модели и реклама

Новость добавляется через PR в `content/news.json`, без внешнего HTML/JavaScript. Новые профили инкубаторов требуют подтверждённых источников с указанием модели и параметров, а не переноса норм «Несушки». Рекламные SDK нельзя добавлять без отдельного обсуждения приватности, согласий и правил магазинов (см. `docs/ADVERTISEMENTS.md`).
