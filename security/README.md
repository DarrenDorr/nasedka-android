# Контроль безопасности «Наседки»

Эти файлы подготовлены на основании предоставленного владельцем `Nasedka_Security_Pack_v1.zip` (17.11.2026). Требования и сценарии проверки — **не свидетельства успешных испытаний**. Результаты записываются только после запуска CI, анализа логов и тестирования на устройствах.

- `PROJECT_SECURITY_PROFILE.yaml` — факты, ожидаемые меры защиты, неизвестные параметры. Обновлён с учётом существования публичного GitHub и текущего исходного кода.
- `ANDROID_SECURITY_BASELINE.md` — обязательные инварианты `NSD-001`—`NSD-050`.
- `NOTIFICATION_TEST_MATRIX.md` — проверочные сценарии; стартовый статус `NOT_RUN`.
- `STORE_RELEASE_POLICY.md` — условия трёх каналов распространения, рекламы и конфиденциальности.
- `REQUIREMENTS_TRACEABILITY.md` — связь пользовательских требований и инструкции к инкубатору.
- `SOURCE_REGISTER.md` — реестр исходных официальных источников; перед релизом требуется актуализация.

**Не включены в GitHub:** исходный PDF производителя (права на распространение не выяснены), универсальные методические `Security_OS_v3.docx`, `Security_Prompts_v3.md` и стартовый промпт. Эти материалы остаются у владельца в исходном ZIP, а проектные обязательные требования представлены текстовыми файлами выше.

Релизные секреты, данные пользователей и реальные ключи подписи нельзя коммитить. Новые регрессии и доказательства проверок размещаем в будущих `security/evidence/` и `security/regressions/` без личных данных.
