# Поведение при повороте экрана (v0.4.1-dev)

**Проблема (HONOR X7b):** при случайном повороте телефона закрывались активные всплывающие диалоги и пропадали несохранённые отметки/поля. В v0.4.0-dev новый мастер инкубации использует последовательность `AlertDialog`, `Spinner`, `CheckBox`, `EditText` и диалоги выбора даты/времени; приложение не имело специальной обработки изменений ориентации.

**Решение:** `android:configChanges="orientation|screenSize|smallestScreenSize|screenLayout|keyboardHidden"` для `MainActivity`; переопределён `onConfigurationChanged` с вызовом `super`, **без** пересоздания интерфейса. Нативная иерархия Views и Dialog остаётся в памяти, а Android пересчитывает её размеры для нового окна. Принудительная портретная ориентация не установлена. Выбранная вкладка, ID закладки и ID экспорта сохраняются через `onSaveInstanceState` для других перезапусков.

**Почему именно так на данном этапе:** текущий экран полностью строится из нативных Views, размеры основаны на dp, длинные формы обёрнуты в `ScrollView`; отсутствуют ресурсы компоновки, зависящие от ориентации. Обработка только изменений размера минимально влияет на уже проверенные уведомления, SQLite и мастер инкубации.

**Ограничения:** это решение не обеспечивает сохранения **черновиков диалогов** при уничтожении процесса, смене языка/темы, очистке приложения системой и т.п. Полное восстановление черновиков требует дополнительного lifecycle-состояния и отдельных тестов. Автоматический JVM-тест проверяет контракт AndroidManifest, а не фактический поворот физического телефона.

**План физического ретеста:**
- В мастере инкубации на шагах 1, 2, 3 перевернуть телефон несколько раз и вернуться; проверить, что окно не закрылось, а модель, отметки, введённые данные и выбранные дата/время сохранились.
- Открыть диалог фактических показаний и вручную ввести температуру, затем повернуть экран; проверить сохранение значения и запись.
- Проверить настройку напоминаний, диалог завершения и возвращение из экрана приложения, чтобы не было лишнего сброса вкладки.
- Проверить альбомную ориентацию с открытой клавиатурой и прокруткой на HONOR X7b.
- Проверить уведомления: у изменения нет связи с AlarmManager/NotificationChannel и не должно быть регрессии доставки/звука.

Документация Android: https://developer.android.com/guide/topics/resources/runtime-changes .
