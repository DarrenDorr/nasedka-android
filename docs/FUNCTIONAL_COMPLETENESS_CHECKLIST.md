# Матрица функционального завершения — 0.8.0-dev

Главный принцип: **функции перед дизайном**. Графическое оформление, иконки и анимации отдельная работа после полного функционального QA; неточности данных исправлять сейчас, не откладывать до дизайна.

| Направление | Что доступно в коде | Что необходимо доказать на устройстве |
|---|---|---|
| Инкубатор | Мастер подготовки, профиль «Несушка», дневник, температура/влажность вручную, календарь, события, итоги, CSV | Сохранение данных, длительные уведомления и звук, обновление поверх прежнего APK |
| Под наседкой | Начало, вид, яйца, наседка/гнездо, наблюдения, сроки, вывод, напоминания, перенос молодняка | Уведомления при заблокированном телефоне, учёт завершения и перенос без дублей |
| Поголовье | Группы, возраст по дате, поступление/выбытие, переводы, учёт молодых птиц, осмотры | История после перезапуска, запрещён отрицательный остаток |
| Корма | Позиции, единицы, покупка/расход, баланс, связь стоимости покупки и финансов | Цена отражается один раз, расход не дублирует финансовую операцию |
| Финансы | Доходы, расходы, рубли/копейки, категории, периоды | Правильность сумм и округления |
| Сбор яиц | Сбор по группам и дата | Правильность суммирования за периоды |
| Задачи ухода | Даты, время, описание, ручное выполнение, фоновое напоминание | Получение в фоне, Doze, после перезагрузки |
| Отчёты | Денежный итог, поголовье, активная инкубация, выводимость, яйца, корм | Точность при пустых данных и при реальных записях |
| Резервирование | Полный JSON экспорт и поэтапный импорт обеих баз, откат аварии | Реальная проверка на копии данных; поломка файла должна блокироваться без потерь |
| Дистрибуция | 3 debug flavor и CI, новости из GitHub | Постоянная релизная подпись, безопасное обновление и store SDK ещё не готовы |
| UI | Все модули доступны через существующий простой нативный интерфейс | Красивый дизайн будет позже, однако блокирующие функциональные ошибки исправлять немедленно |

## Остаётся до функционального релиза
- [ ] Полный физический регрессионный тест / резервирование / импорт / аварийный откат на устройстве.
- [ ] Подтверждённые источники для ухода за наседкой и охлаждения яиц (не выдумывать нормы).
- [ ] Данные о результатах овоскопирования и отдельное редактирование ошибочных записей без потери истории.
- [ ] Кормовые партии/сроки годности и распределение расхода по группам птицы.
- [ ] Индивидуальные карточки птицы только при реальной необходимости.
- [ ] Подписи релизов, политика конфиденциальности, store SDK и действия перед публикацией.
- [ ] Масштабирование JSON-резерва сверх лимита 24 МБ, если необходимо.
- [ ] Проверить запрет двойного переноса молодняка, смену часового пояса и перезагрузку.
