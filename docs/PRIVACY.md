# Черновик технической информации о приватности

**Это рабочая техническая заметка, НЕ юридически готовая политика конфиденциальности для публикации.** Перед добавлением рекламных/аналитических SDK и магазинной модерацией потребуется актуальный документ с реквизитами правообладателя и контактами.

- Закладки, параметры, результаты измерений и выполненные действия хранятся на самом устройстве в SQLite. В коде `RemoteFeed` **не отправляет** эти данные в интернет.
- При включённом интернете и настроенном GitHub-репозитории приложение обращается по HTTPS к публичным GitHub Releases API и `raw.githubusercontent.com` не чаще одного раза в 24 часа при использовании приложения, а также по запросу пользователя. Серверам доступны обычные сетевые сведения, в том числе IP-адрес; конкретные условия обработки определяются GitHub.
- Google Play/RuStore сборки по нажатию открывают магазин, который применяет собственные политики обработки данных.
- В текущем коде **нет встроенных рекламных SDK**, аналитики, аккаунтов и синхронизации. Если они появятся, потребуется пересмотреть публичную политику, согласия и магазинные декларации.
- Удаление закладок происходит пользователем в приложении. Экспорт CSV создаётся только после выбора файла пользователем.
