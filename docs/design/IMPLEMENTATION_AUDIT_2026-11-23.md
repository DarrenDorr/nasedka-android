## Найденные архитектурные ограничения

1. **Две локальные SQLite** (`incuba.db` и БД хозяйства), обе со схемой v2; без протестированных миграций не изменять структуры действующих данных.
2. Для естественной инкубации точная дата сохраняется как обязательный timestamp. Чтобы добавить «Дата неизвестна», понадобится явная миграция и отдельное отображение неопределённости.
3. `BackupStore.java`: пользовательский экспорт имеет лимит 24 МБ; не считать полноценной фото-резервной копией.
4. `MainActivity.onResume()` пересоздаёт экран через `render()`; необходимо отдельно проверить сохранение форм после фоновых событий. На повороте конфигурация перехватывается, но этого **не достаточно** для сохранения ввода после уничтожения процесса.
5. Текущая программная верстка и отсутствие загруженных 43 оригинальных PNG означают, что **утверждённый визуал ещё не реализован пиксельно**.
6. Сборка/наличие unit-тестов не подтверждает успешное вручную пройденное тестирование на устройстве.

Через GitHub Actions получен факт: среди последних запусков workflow `Android build and tests` имеется завершённый со статусом `success` от 23.11.2026, но несколько предыдущих завершились `cancelled`. Это только состояние GitHub Actions, а не результаты проверки конкретной функции на HONOR.

## Очередь реализации после переноса оригиналов

1. **R0 — доказательная база:** загрузить оригиналы PNG (без перерисовки), проверить 43 SHA-256; синхронизировать реестр.
2. **R1 — сохранность:** тесты резервных копий/миграций/черновиков/уведомлений, исправить дефекты, если подтверждены.
3. **R2 — дизайн-каркас:** четыре вкладки, Главная, общие карточки/навигация по утверждённым эталонам (без уничтожения существующих функций).
4. **R3 — первичные учётные операции:** яйца и финансовые связи, корректировки и единый журнал — только после фиксации схемы и тестов.
5. **R4 — естественная инкубация и выращивание:** два сценария, неизвестная дата, постраничные инструкции, проверенные возрастные профили.
6. **R5 — остальной утверждённый UI:** поголовье, корма, финансы, отчёты, новости, настройки, напоминания, бэкапы, пустые/ошибочные состояния.
7. **R6 — визуальная и физическая валидация**, затем иконка, юридические страницы и подготовка выпуска.

**Этот документ — точка сверки, а не команда начать массовый рефакторинг.** До отдельного согласования код приложения не меняем.
