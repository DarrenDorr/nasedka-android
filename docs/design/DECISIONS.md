# Постоянные решения проекта «Наседка»

**Правило:** этот документ — не пожелания на будущее, а реестр пользовательских согласований. Изменение решения возможно только по новому явному запросу; прежнее остаётся в истории.

| ID | Решение | Следствие |
|---|---|---|
| D-001 | Заморожен кремово-зелёный пятиэкранный эталон | Не менять самостоятельно цвета, компоновку, иллюстрации и стиль |
| D-002 | Нижние вкладки строго «Главная · Новости · Журнал · Настройки» | Инкубация, Поголовье, Яйца, Корма, Финансы, Отчёты доступны из Главной; напоминания по колокольчику |
| D-003 | «Наседка» — учёт домашней птицы и в будущем всего хозяйства | Инкубация — модуль, а не целое приложение |
| D-004 | Инкубация: два различных способа «В инкубаторе» / «Под наседкой» | Не переносить механически одинаковые инструкции |
| D-005 | В инкубаторе сначала выбрать конкретную модель, потом вместимость и подтверждённые функции | Для БИ-1/БИ-2 нельзя додумывать конфигурацию |
| D-006 | Перед первой закладкой иллюстрированный постраничный мастер | Вводный экран содержит кликабельную официальную инструкцию, а страницы сразу объясняют действия |
| D-007 | Для наседки два входа: готовим наседку / птица уже самостоятельно села | «Дата неизвестна» не превращается в выдуманный день инкубации |
| D-008 | Единый журнал хозяйства со списком, фильтрами, календарём и карточкой исправлений | Не создавать отдельные дубли событий |
| D-009 | Один реальный факт порождает один исходный учётный акт и согласованные представления | Инкубация, запасы, финансы, журнал и отчёты связаны |
| D-010 | Учёт яиц: заложено, удалено, осталось, вылупилось, исход неизвестен | Овоскопирование само по себе не уменьшает количество |
| D-011 | Выведенные птенцы добавляются в поголовье только один раз | Учётная операция не означает физическое отделение от наседки |
| D-012 | Группы поголовья имеют историю движений | Перевод между группами не изменяет общее количество |
| D-013 | Сбор и покупка яиц, повреждения, продажи, потребление и передача в инкубацию | Нет повторного прихода/расхода, нет отрицательного остатка |
| D-014 | Покупка корма создаёт приход корма и один финансовый расход | Кормление не создаёт вторую денежную трату |
| D-015 | Финансы — денежные операции, отчёты — аналитика по реально введённым данным | При нехватке данных себестоимость не выдумывать |
| D-016 | Возрастные рекомендации зависят от вида птицы и назначения; проверять источники | Нет автоматического назначения лечения; при проблемах обращаться к ветеринару |
| D-017 | Первый запуск — объяснение рекомендательного характера советов, условия и приватность | Не обещать гарантированных результатов |
| D-018 | Нет обязательной регистрации, точной геолокации и адреса | Регион — только добровольно и позже, пока убрать из интерфейса |
| D-019 | Центр уведомлений по колокольчику; выполнение/отложено/пропущено — разное | Android может задержать сигнал, экран блокировки на HONOR не обещать |
| D-020 | Резервная копия — не отчёт CSV/PDF; файл проверяется перед восстановлением | Защита существующей базы и подтверждение действий |
| D-021 | Исправления с историей прежних значений и причины; безопасная отмена/архивирование | Не удалять связанные операции бесследно |
| D-022 | Поворот экрана и пересоздание интерфейса не стирают формы | Черновик не изменяет учёт до подтверждённого сохранения |
| D-023 | Новости не дублируют журнал пользователя | Реклама позднее, без перекрытия важных задач |
| D-024 | Температура/влажность только ручные без подключённых датчиков | Не выдавать заводскую/целевую температуру за измеренную |
| D-025 | Код Apache-2.0; ключи подписи не публиковать | Каналы GitHub/Play/RuStore обновляются по своим правилам |
| D-026 | Иконка приложения создаётся последней | Не тратить этапы на оформление иконки до завершения UI |
| D-027 | Сначала дизайн и согласование, затем реализация поверх существующего кода | Не переписывать проект с нуля, не менять код без разрешения |
| D-028 | Все экраны, PNG, статусы, ошибки, история изменений и следующий этап фиксируются | Без повторной генерации уже согласованного |

## Не путать согласование с фактической реализацией

**`0.9.0-dev`** — версия исходников, указанная в README GitHub; это не означает проверенный выпуск. Результаты физического тестирования, в том числе уведомлений HONOR X7b, отдельно сверять с текущими доказательствами.

## Зафиксированные контрольные примеры

- Инкубация: 104 яйца − 6 подтверждённых удалений = 98 к выводу; 90 птенцов вылупились; 8 оставшихся яиц без утверждённого исхода. Отдельные знаменатели для разных процентов выводимости.
- Под наседкой: 8 заложено, 1 удалено, 7 осталось; 6 вылупилось — у одного статус не определён без действия пользователя.
- Учёт яйца: 24 собрано − 2 повреждены − 6 переданы в инкубацию = 16 доступны (условный пример).
- Корма: +20 кг за 800 рублей = одна закупка и один денежный расход; дальнейшее кормление −2 кг не создаёт новый платёж.
- Молодняк: перенос из партии в группу выполняется один раз, дальнейшее изменение количества — отдельная операция.

## Ошибки сгенерированных изображений

Неверное выделение вкладки `Журнал` на вложенных экранах, несогласованные даты, опечатки, фиктивные версии/метрики, наличие кнопки безвозвратного удаления и формулировки, способные обещать физическое отделение цыплят, **не становятся требованиями**. Приоритет у данного реестра и подтверждённых пользовательских решений.
