## Общие правила для всех экранов

- Полная копия данных ≠ экспорт CSV/PDF/Excel.
- Подтверждение выполнения ≠ отправка уведомления; черновик ≠ проведённая операция.
- Для инкубатора измерения вносятся вручную, для естественной инкубации не показывается ручной поворот.
- У птицы/яиц/кормов/денег не бывает отрицательных остатков и повторного прихода.
- Все важные действия фиксируются в одном журнале, а история исправлений не исчезает.
- Опечатки и условные цифры на графических макетах не становятся источником расчётов.
- Начало кодирования только после сверки экранов с реальными исходниками и отдельного разрешения пользователя.

**При последующих изменениях** добавлять ID/дату/решение/PNG/SHA-256 и обновлять `docs/PROJECT_STATUS.md`; не заменять «утверждено» на «реализовано» без тестов.
