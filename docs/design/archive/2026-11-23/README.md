# Наседка — полный архив утверждённых макетов и правил (23.11.2026)

**Этот архив нужен, чтобы не повторять дизайн и этапы разработки.** Здесь 43 уникальных PNG-файла (байты исходных изображений не изменены), спецификации экранов, дата/решения, текстовый реестр и 4 контактных листа, позволяющих быстро найти нужную картинку. Проверка полноты относится к доступным файлам текущего проекта, а не ко всему когда-либо созданному в ChatGPT.

**Начните с:** `docs/PROJECT_STATUS.md`, затем `docs/DESIGN_SYSTEM.md`, `docs/DECISIONS.md`, `docs/SCREEN_REGISTRY.md`, `index/IMAGE_MANIFEST.csv`. В `index/sheet_*.jpg` все изображения представлены как каталог-превью — эти листы служебные, не эталоны.

**Приоритет:** `assets/approved/` — 3 строгих эталона, задают внешний вид. `assets/concepts/` — модули/сценарии; их картинка сама по себе не гарантирует отсутствия опечаток и числовых противоречий. `assets/historical/` — промежуточные/заменённые.

Для публичного GitHub безопаснее размещать **только графику, на которую у проекта есть права**, и дизайн-документы. Оригинальное руководство производителя `references/incubat_2021.pdf` включено в личный архив как ранее предоставленный источник, **но не должно автоматически выкладываться в публичный репозиторий без проверки авторских прав**. Security Pack также не нужен для пользовательского релиза.

`SHA256SUMS.txt` содержит хэши файлов архива (кроме самого списка); `index/IMAGE_MANIFEST.csv` связывает исходные имена с нормализованными путями и статусами. Никакой код Android в этом наборе не менялся.
