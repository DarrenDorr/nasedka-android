## Что фиксируется без изменений

- Цветовая палитра (светлый кремовый фон, зелёные акценты), шрифтовая иерархия, радиусы, отступы, карточки, иллюстрации, значки, порядок элементов и декоративный пейзаж.
- Верх: «Наседка», «Добро пожаловать в ваше хозяйство!», рисунок курицы с цыплятами, колокольчик с индикатором.
- Три показателя в одном ряду: «яйца сегодня», «вывода в работе», «птиц в хозяйстве».
- Большой модуль «Инкубация» с рисунком инкубатора, числом закладок и кнопкой «Перейти».
- Заголовок «Быстрый доступ» и сетка из четырёх модулей 2×2: «Поголовье», «Корма», «Финансы», «Отчёты».
- Декоративный низ с пейзажем / забором / домиком.
- **Фиксированная нижняя навигация (ровно четыре кнопки):** «Главная», «Новости», «Журнал», «Настройки». На главном экране активна «Главная».

## Только логическая привязка; оформление не меняется

| Элемент | Реальные данные / действие |
|---|---|
| Яйца сегодня | Записи сбора яиц из учёта хозяйства за текущий день пользователя |
| Вывода в работе | Количество активных закладок: инкубатор и под наседкой; определение метрики нужно явно согласовать до реализации |
| Птиц в хозяйстве | Сумма фактических остатков по группам птицы |
| Инкубация · Перейти | Открывает существующий раздел инкубации с двумя методами: инкубатор / под наседкой |
| Поголовье | Учёт групп, возрастов, поступления, выбытия и ухода |
| Корма | Запасы, поступления, списания, покупки |
| Финансы | Доходы, расходы, история операций |
| Отчёты | Сводки по птице, кормам, яйцам, финансам и инкубации |
| Колокольчик | Вход к уведомлениям/задачам; способ отображения текущего состояния требуется согласовать, без изменения положения и вида иконки |
| Новости | Новостная лента проекта и материалы |
| Журнал | История записей и задачи |
| Настройки | Системные разрешения, уведомления, другие параметры |

Числа 104, 3 и 27 на картинке — **демонстрационные**, не реальные данные пользователя. При реализации в их местах должны отображаться сохранённые значения; расположение карточек и дизайн при этом не изменяются.
