# Журнал решений — сохранять без повторных согласований

| ID | Закреплённое решение | Ограничение |
|---|---|---|
| D-001 | Утверждён кремово-зелёный эталон из пяти телефонов, отдельные кадры Главной/Инкубации | Самостоятельный редизайн запрещён |
| D-002 | Строго четыре нижние вкладки: Главная, Новости, Журнал, Настройки | Другие модули открываются из Главной |

| D-006 | Под наседкой: подготовить птицу / птица уже сама села; точная, приблизительная либо неизвестная дата | При неизвестной дате не создавать точный отсчёт |

| D-011 | Поголовье: группы и движения с историей, перевод между группами не меняет сумму | Отрицательный остаток запрещён |
| D-012 | Учёт сбора/покупки/повреждения/использования/продажи яиц связан с финансами и инкубацией | Количество и стоимость не дублируются |
| D-013 | Корма и финансы: покупка влияет на физические запасы и денежные расходы; выдача корма не платёж | Отчёты считать только по данным |
| D-014 | Возрастные рекомендации: по виду птицы, назначению и проверенным источникам; советы рекомендательные | Не назначать лекарства, не обещать результат |
| D-015 | Первый запуск: информация об ограничениях, ссылки на условия и политику приватности | Регион пока отсутствует; GPS не запрашивать |
| D-016 | Центр уведомлений по колокольчику; проверка Android и HONOR; напоминание/выполнение/пропуск — разные состояния | Не обещать включение заблокированного экрана |

| D-019 | Поворот, смена размера окна и фон не должны сбрасывать формы; черновик ≠ сохранённая операция | Все формы и мастера проверять |

**Расхождение:** изображение с ошибкой или внутренним несоответствием не отменяет ясного пользовательского решения. Оно отмечается как `REFERENCE`/`PRESENTED` и уточняется в реестре, не перерисовывая всю композицию.
