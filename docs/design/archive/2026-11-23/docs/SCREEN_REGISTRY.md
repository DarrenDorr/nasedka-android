## Статус и дисциплина

- `locked`: точный утверждённый эталон; менять только по прямому решению пользователя.
- `approved_concept`: смысл и визуальное направление обсуждены/приняты; не означает полного пиксельного согласования всех деталей.
- `presented`: показано, но отдельное формальное утверждение ещё отсутствует.
- `reference`: промежуточный рисунок, пример либо неполный вариант; проверять перед использованием.
- `superseded`/`historical`: хранить для истории, не возвращаться к нему как к актуальному.

## Главные связи навигации

- **Главная** → Инкубация → выбор «В инкубаторе» / «Под наседкой» → мастер → карточка партии → календарь/наблюдения → результат → существующая группа молодняка.
- **Главная** → Поголовье → группа → уход и движения; молодняк после вывода использует ту же карточку группы.
- **Главная** → Корма и запасы → поступление/расход → связанные деньги → единый журнал.
- **Главная** → Сбор яиц → сбор/покупка → использование (продажа, еда, инкубация, списание) → остатки/отчёты.
- **Главная** → Финансы → операции → отчёты; **Главная** → Отчёты → только аналитика.
- **Колокольчик** → единый центр задач; **нижнее меню** → Главная, Новости, Журнал, Настройки.

## Замечания, которые нельзя копировать как продуктовую логику

- Все числа на макетах условные. Пример инкубатора: 104 заложено − 6 подтверждённо удалено = 98 к выводу; вылупилось 90; исход оставшихся 8 не определён автоматически.
- Пример натурального насиживания: 8 яиц, 1 удалено, 7 осталось; в итогах с 6 птенцами ещё 1 яйцо может оставаться без установленного исхода.
- Макеты «Новости» могут содержать вымышленные даты/версии; не публиковать их как реальные.
- Некоторые сгенерированные экраны показывают активную вкладку «Журнал» там, где она не соответствует маршруту; при переносе сделать актуальное выделение, сохранив стили.
- На изображении об удалении могут быть прямые кнопки безвозвратного удаления — следовать D-018: важные записи безопасно отменять/архивировать и сохранять историю.
- На иллюстрациях встречается краткая инструкция или неправильное значение времени: при разработке приоритет за точным пользовательским требованием и подтверждённым источником.

## Ключевые отсутствующие состояния для реализации

Пустые экраны, длинные названия, несколько закладок, нулевые значения, ввод отрицательных/неверных количеств, удаление связанных данных, клавиатура, перенос черновика при повороте, Doze/перезагрузка и ограниченные разрешения, ошибки сети и при импортировании резервной копии.

## Как регистрировать новый макет

Добавить оригинальный PNG без изменений, вычислить SHA-256, внести ID/путь/тип/статус в `index/IMAGE_MANIFEST.csv`, указать пользовательское подтверждение в `DECISIONS.md`, текущую задачу в `PROJECT_STATUS.md`. Ранее принятый файл не заменять без истории.
