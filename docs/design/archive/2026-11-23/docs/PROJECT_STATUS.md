## Статус файлов

- `docs/DESIGN_SYSTEM.md` — что именно запрещено менять.
- `docs/SCREEN_REGISTRY.md` — утверждения, исключения, ссылки на все ключевые графические материалы.
- `docs/DECISIONS.md` — устойчивые решения без повторов.
- `index/IMAGE_MANIFEST.csv` — точные имена, размеры, SHA-256 и статусы всех изображений.
- `assets/approved` — эталоны с уровнем LOCKED. `assets/concepts` — согласованные примеры и дополнительные предложения, **не абсолютный пиксельный эталон**. `assets/historical` — отвергнутые/устаревшие варианты.
- `references` — существующие спецификации, паспорт, аудит, архивы эталонов, пользовательское руководство и security pack (только для частного обмена; права на публикацию исходной инструкции проверить отдельно).

## Порядок работы в новом чате

1. Прочитать `PROJECT_STATUS.md`, `SCREEN_REGISTRY.md`, `DECISIONS.md`, `DESIGN_SYSTEM.md`, `IMAGE_MANIFEST.csv`.
2. Проверить актуальный GitHub README, ROADMAP, код/CI перед утверждением «реализовано».
3. Выполнить только текущую задачу. Если задача уже в реестре — не повторять; искать следующую незавершённую.
4. При утверждении экрана внести **название файла, SHA-256, визуальный статус и номер решения**; старое изображение оставить как историю.
5. После каждого шага обновить эту точку продолжения: сделано → сейчас → дальше → что остаётся неподтверждённым.
