# UI ↔ исходный код: матрица проверки перед переносом дизайна

> Источник начального статуса — README.md и ROADMAP.md GitHub (`0.9.0-dev`); исходники в этой ревизии отдельно не аудировались. Ниже нет утверждения о пройденных тестах.

| Модуль | Есть по README/ROADMAP | Дополнительно по UI | Как подтвердить |
|---|---|---|---|
| Главная | Базовая сводка хозяйства | Воспроизвести пиксельный эталон, четыре нижние вкладки | Снимок экрана и тест навигации |
| Инкубатор | Закладки, БИ-1/БИ-2, напоминания, подготовка, дневник | Постраничная иллюстрированная инструкция и подтверждённая конфигурация | E2E закладки/событий, сверка с руководством |
| Наседка | Базовый дневник и уведомления | Два сценария старта, неизвестная дата, уход, вывод | E2E оба сценария |
| Молодняк | Группы и однократный перенос вылупившихся | Возрастные инструкции и история ухода | Проверка общих остатков |
| Поголовье | Группы, переводы и движения | Развитая карточка, история корректировок | Тест переводов и исправлений |
| Корма | Закупки/расход/остатки | Фильтры, срок/партия и рекомендации | Контроль финансовых связей |

| Backup | Заявлены SQLite экспорт/импорт | UI подтверждений, валидатор, переключение копий | Физический restore и аварийное прерывание |
