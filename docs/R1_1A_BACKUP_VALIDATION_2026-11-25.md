# R1.1a — валидация резервных копий и SQLite fixtures

Дата 25.11.2026. База: аудит 2abd234ecc00dbc12d11b7e1994c13bb1be6f133, PR #7. Продолжение согласовано пользователем; это первый узкий патч R1.1, не релиз.

## Изменения
- BackupStore.validate: все массивы инкубации и хозяйства обязательны; только отсутствующий flock_notes для farm_version=1 нормализуется в пустой массив. Неправильный тип не маскируется. populate не создаёт отсутствующие таблицы из пустых массивов.
- relations: перенос из инкубатора требует существующей группы и положительного количества, дополнительно к проверке batch_id. Формат JSON v1 и обе SQLite v2 сохранены.
- Добавлены 7 Android instrumentation tests (AndroidX Test Runner 1.6.2, ext junit 1.2.1, фиксированные test-only зависимости). Тесты работают с in-memory SQLite, не открывают реальные базы. Existing CI дополнительно собирает APK тестов, не запускает эмулятор и не публикует test APK.
- Дизайн, версия приложения, бизнес-правила и UI неизменны.
